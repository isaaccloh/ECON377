# ECN 377 — Fall 2026 class code

Starter R scripts for each class day. **Download or fork, and run along in class.**

## Getting the code
- **Download:** click the green **Code** button → **Download ZIP** (or open a single file and copy it).
- **Fork (optional):** click **Fork**, then use **Sync fork** to pull in updates. You can edit your own copy freely.

## Layout
```
377_2026/
  D01/D01_starter.R
  D02/D02_starter.R
  ...
```
Each `D<nn>_starter.R` is the script for that day. In the comments:
- `# TODO` marks the one or two things we fill in together in class,
- `KNOW THIS` marks code you're responsible for on quizzes and exams.

Data comes from the `wooldridge` package — install it once with `install.packages("wooldridge")`.

*(Lecture notes and answer keys are not posted here.)*
